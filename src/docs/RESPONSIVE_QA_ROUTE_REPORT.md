# Torch Republic Responsive QA Route Report

Scope: code-based responsive QA and consistency repair across public storefront routes, without changing product data, pricing, checkout, integrations, or creating pages. Target widths reviewed against implementation requirements: 320, 360, 375, 390, 414, 430, 768, 820, 1024, 1280, 1440.

Important testing note: the repaired code passed a production build. A final live visual/browser pass at each target width should be run with the Base44 Testing Agent before treating this as device-certified. Full accessibility compliance is not claimed.

## Repairs Applied

- Homepage hero: already updated to the approved light botanical layout with mobile stack, responsive product crop, no text over packaging, and trust points after the image.
- Global search dialog: removed 100vw-plus-margin overflow risk and increased close control to approximately 44px.
- Shop: corrected remaining dark/low-contrast newsletter and bundle copy styling; improved mobile filter/button touch targets; preserved the public title “Shop Instant Coffee, Mushroom Coffee & Matcha.”
- Build Your Ritual: prevented selection beyond three items, disabled out-of-stock selections, made product selection cards keyboard-operable buttons, removed sticky summary behavior on mobile, added bottom spacing for the fixed mobile CTA, and prevented hero stat overflow.
- Reviews: stacked filter controls on mobile, made review filters/selects full-width on phones, and increased form control text sizes.
- Customer Spotlight: kept approved-only story query, preserved customer image aspect ratios, and improved mobile form control text sizes.
- Founder Story: removed black legacy backgrounds and converted the page to the approved light botanical palette.
- Duplicate bundle route: `/bundle` now redirects to `/build-your-ritual`, was removed from the public pages sitemap, and is canonicalized/noindexed.

## Accessibility Checks Performed

- Keyboard operability improved for Build Your Ritual product selection by converting clickable cards into buttons.
- Form labels are present on Reviews and Customer Spotlight; mobile input text size increased to at least 16px.
- Touch target sizing improved for search close, shop category filters, Build Your Ritual tabs, and removal controls.
- Contrast risk reduced on Shop and Founder Story by removing dark-theme remnants and unreadable pale text.
- Product images continue to use `object-contain` where products are displayed; no product/pricing data changed.

## Remaining Risks

- This was a code-based responsive repair plus build verification, not a full live visual certification at every width.
- Carousels, dialogs, focus order, reduced-motion behavior, and every retained dynamic article/product page still need a live Testing Agent pass.
- Owner should confirm whether Founder Story remains separate from Our Story and whether FAQ/legal pages should remain noindexed.
